# Stakeholder Memo

**Stakeholder:** Portfolio Manager  
**Decision:** Whether current conditions justify reviewing or reducing momentum exposure.

Momentum can deliver strong long-run returns but can also go through sharp periods of relative weakness. This project asks whether information available at month-end can identify a higher-risk environment for the following month.

The output is a probability that an S&P 500 momentum proxy (SPMO) will underperform SPY in the next month. It is intended as a risk-review input, not an automatic trading instruction. A useful result would be stable out-of-sample ranking ability and a clear understanding of when the model fails.
